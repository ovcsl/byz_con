.1.1.112Plaintiff is owner0AktionThe decisive passage is the explicit condictio: “condictioni locus est quasi re non secuta,” after one party has delivered in exchange and the counter-performance fails. The claim is for restitution because the expected causa did not follow, not because the claimant asserts continuing ownership of the delivered thing. This is a personal condictio ob rem dati/re non secuta, not a vindicatory claim. Conclusion: the criterion is not satisfied.

This is an exchange or innominate-contract failure, not a credit of fungibles to be repaid in the same kind and quantity. No mutual intention to create a mutuum appears; conclusion: not satisfied.

The text contrasts an action for the claimant’s interest with the condictio for return of the res itself. That is a determinate restitutionary object pursued by condictio, so the criterion is satisfied.
